# Proyecto Ciudades Journey

Este repositorio contiene un proyecto en **RStudio** para analizar datos relacionados con ciudades.  
El proyecto está configurado como un archivo `.Rproj`, lo que permite abrirlo directamente en RStudio.

---

## Requisitos

1. **Instalar R**  
   Descargá la versión más reciente desde [CRAN](https://cran.r-project.org/).

2. **Instalar RStudio (recomendado)**  
   Descargá RStudio desde [posit.co/download/rstudio](https://posit.co/download/rstudio).

3. **Clonar el repositorio**

   ```bash
   git clone https://github.com/FrancoNelliExa/ciudadesJourney.git
